# Blinkit Sales & Outlet Analysis Dashboard -- Excel

## 📊 Project Overview

This project is an **interactive Blinkit Sales & Outlet Analysis
Dashboard created using Microsoft Excel**.

The dashboard provides a visual overview of sales performance, outlet
characteristics, item types, outlet locations, outlet sizes, and
customer/product-related metrics. Excel features such as **Pivot Tables,
Pivot Charts, Slicers, formulas, and dashboard formatting** were used to
transform the raw data into an easy-to-understand business dashboard.

## 🎯 Project Objective

The main objective of this project is to analyze Blinkit's sales and
outlet data and identify important business trends, including:

-   Overall sales performance
-   Average sales per transaction/item
-   Number of items
-   Average customer rating
-   Sales by outlet establishment year
-   Sales by outlet size
-   Sales by outlet location
-   Sales by outlet type
-   Item-type performance
-   Fat-content contribution to sales

## 📈 Dashboard Visualizations

### 1. Outlet Establishment

A time-series/area chart shows sales performance according to the outlet
establishment year.

This helps identify:

-   Sales growth and decline over time
-   The year with the highest sales
-   Changes in outlet performance across different establishment periods

### 2. Fat Content Analysis

A donut chart compares sales generated by:

-   Low Fat
-   Regular

This helps understand which fat-content category contributes more to
overall sales.

### 3. Item Type Analysis

A bar chart compares sales across different item categories such as:

-   Fruits and Vegetables
-   Snack Foods
-   Household
-   Frozen Foods
-   Dairy
-   Canned
-   Baking Goods
-   Health and Hygiene
-   Meat
-   Soft Drinks
-   Breads
-   Hard Drinks
-   Starchy Foods
-   Breakfast
-   Seafood

This helps identify the highest- and lowest-performing item categories.

### 4. Fat Content by Outlet

The dashboard compares **Low Fat and Regular** products across different
outlet locations/tiers.

This allows users to understand how product composition varies across
outlet locations.

### 5. Outlet Size Analysis

A donut chart displays sales contribution based on outlet size:

-   High
-   Medium
-   Small

This helps determine which outlet size generates the highest sales.

### 6. Outlet Location Analysis

A bar chart compares sales across:

-   Tier 1
-   Tier 2
-   Tier 3

This helps identify which location tier contributes the most revenue.

### 7. Outlet Type Analysis

The dashboard compares different outlet types, including:

-   Supermarket Type 1
-   Supermarket Type 2
-   Supermarket Type 3
-   Grocery Store

Metrics displayed include:

-   Total Sales
-   Average Sales
-   Number of Items

## 🎛️ Interactive Filters

The dashboard includes slicers/filters that allow users to analyze the

-   **Outlet Size**
    -   High
    -   Medium
    -   Small
-   **Outlet Location**
    -   Tier 1
    -   Tier 2
    -   Tier 3
-   **Item Type**
    -   Baking Goods
    -   Breads
    -   Breakfast
    -   Canned
    -   Dairy
    -   Frozen Foods
    -   and other categories

Users can select one or multiple filter values to view specific segments
of the business.
